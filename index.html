Theoretical Reference: Instruction Cycle & Interrupt Servicing

1. THE 3 FUNDAMENTAL CYCLE PHASES

Fetch Phase (T0 – T2):

The address from PC is placed on the Address Bus via MAR. Memory read signal is asserted; instruction word enters MDR across Data Bus; PC is incremented (PC ← PC + 1); instruction loaded into IR.

Decode Phase (T3):

Control Unit extracts the 8-bit opcode, resolves addressing modes, and prepares the control matrix for functional units.

Execute Phase (T4 – T6):

ALU operations, memory read/write operands, conditional branch tests, and register writebacks are completed.

2. THE INTERRUPT PHASE (TINT0 – TINT4)

Interrupt Check:

At the end of every instruction's execute cycle, hardware probes the INTR line and Interrupt Enable (IE) flip-flop.

State Preservation (Stack Frame):

The CPU decrements SP and pushes the return address (PC) onto the stack. It then decrements SP and pushes Accumulator (AC) and flags.

Vector Branch:

PC is loaded with the entry point of the Interrupt Service Routine (ISR) at address 0x28, and IE is cleared (disabled) to prevent re-entrant collision.

Return via IRET:

The ISR concludes with IRET, popping AC and PC from the stack and restoring the main program.
